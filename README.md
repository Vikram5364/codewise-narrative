
# CodeWise - Interactive DSA Learning Platform

## Project Overview

CodeWise is an interactive platform designed to help users learn data structures and algorithms through engaging videos and challenges.

## Features

- Interactive data structure and algorithm visualizations
- Video lessons with step-by-step explanations
- Coding challenges to practice implementation
- Progress tracking and achievements
- Responsive design for all devices

## Tech Stack

This project is built with:

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn/ui components
- React Router for navigation
- Recharts for data visualization

## Development

To run this project locally:

```sh
# Step 1: Clone the repository
git clone <YOUR_REPOSITORY_URL>

# Step 2: Navigate to the project directory
cd codewise

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Project Structure

- `/src/components` - UI components
- `/src/pages` - Page components
- `/src/data` - Sample data and mock APIs
- `/src/hooks` - Custom React hooks
- `/src/types` - TypeScript type definitions
- `/src/lib` - Utility functions
